# Photo printers for tiny photo booth

## What the guest walks away with

One long glossy strip: **2 inches wide, 6 inches tall, with four photos stacked vertically down it.** The classic wedding / event booth keepsake.

```
  2"
┌──────┐
│ pic1 │
│ pic2 │  6"
│ pic3 │
│ pic4 │
└──────┘
```

Every printer below produces exactly this. The only question is which machine.

---

## How booth strips are made

The printer does **not** load 2×6 paper. It loads a **4×6** roll, software lays two identical strips side by side on one sheet, and the printer's built-in cutter **splits the sheet into two finished 2×6 strips**.

So one 4×6 sheet = two complete four-photo strips.

```
+----------- 4 inches -----------+
|  2x6 strip   |   2x6 strip     |
|  photo 1     |   photo 1       |
|  photo 2     |   photo 2       |
|  photo 3     |   photo 3       |
|  photo 4     |   photo 4       |
+--------------- cut ------------+
```

Often one strip for the guest and one for the venue scrapbook — or both to the guest.

### Bigger strips, if wanted later

Loading **6×8 double-perforated media** instead yields **three 2×8" jumbo strips** per sheet (~$178 / 400 prints). Same four-frame look, taller keepsake. Not V1 — noted so the option isn't forgotten.

## Printer choices

### DNP DS620A (preferred for wall mount)

- Fast 4×6 (~8.3s), compact (~10.8 × 14.4 × 6.7")
- 2×6 strips via 2-up cut on 4×6 media
- Street price ~**$985–999** (e.g. PFSNY, FotoClub, Photo Printer Outlet)
- 4×6 media kit ~**$124–145** → 800 sheets → up to **1,600 strips** in 2-up (~$0.08–0.09/strip media)

Best when enclosure depth and speed matter.

### DNP DS-RX1HS (workhorse / capacity)

- Common booth printer; ~12.4s per 4×6; **700** 4×6 per roll
- Larger/heavier (~30 lb, deeper box)
- Street price ~**$695–825**

Best when media changes matter more than a slim wall bay.

### Sinfonia CS2 (lowest cash for real strips)

- ~11s 4×6; auto-splits to two 2×6 strips
- ~10.7 × 13.8 × 6.6"; ~300 4×6 per load
- Street price ~**$675**

Best cheapest path that still looks like a real booth print.
